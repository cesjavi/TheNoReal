Activa la aplicación web

Para ejecutar The Non Real dentro de Capacitor necesitas compilar primero la app de Next.js y copiar los assets generados a la carpeta public/ con npx cap sync android.

Desde la raíz del proyecto ejecuta:

npm run build && npx cap sync android

Si prefieres apuntar a una URL desplegada, configura server.url en capacitor.config.ts y vuelve a sincronizar.

Este marcador de posición se mostrará hasta que la compilación de Next.js genere el contenido final.
